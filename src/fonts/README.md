# Bundled fonts

Both faces are licensed under the SIL Open Font License 1.1, which permits
bundling and redistribution, including in commercial work. The licence asks that
the copyright notice and licence text travel with the font files, which is what
the two `OFL-*.txt` files here are for. Keep them alongside the fonts.

| file | family | copyright | licence |
| --- | --- | --- | --- |
| `fredoka-var.woff2` | Fredoka (variable, 400 to 700) | 2016 The Fredoka Project Authors | [OFL-Fredoka.txt](./OFL-Fredoka.txt) |
| `andika-400.woff2`, `andika-700.woff2` | Andika | 2004 to 2026 SIL Global | [OFL-Andika.txt](./OFL-Andika.txt) |

Both carry Reserved Font Names: "Fredoka" for the first, "Andika" and "SIL" for
the second. That only restricts modified versions, which must be released under
a different name. These files are unmodified latin subsets taken from the Google
Fonts CDN, so the restriction does not apply here.

Andika is not a decorative choice. SIL designed it for literacy, and its
single-storey `a` and `g` match the letterforms children are taught to write, so
it sets the words being spelled. Fredoka handles the interface.
